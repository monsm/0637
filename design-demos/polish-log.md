# 打磨记录 · 三方向初稿（2026-11-21）

每版一轮：看自己的截图，写下最伤的三处，改，再截。

## A · 房间里的物件（`A-room-objects.html`）

第一轮看到的最伤三处：
1. 鸭子图裁切错位——只露半身，图画在房间里有可见的矩形边。
2. 墙上的钟（时间机器入口）读起来像「返回」箭头。
3. 第二行只有一台手机，右侧大片空，画面失衡。

改法：按显示比例重裁鸭子（600×995）并加椭圆蒙版羽化边缘；钟面加 12/3/6/9 刻度、12 点琥珀色；把「房间的仪表」与「技能卡盒」并排成第二行。

## B · 一天有形状（`B-day-shape.html`）

第一轮看到的最伤三处：
1. 印章页上半屏是一块空洞，时间线只剩一根线。
2. 「午后」章节文字贴到卡片下缘。
3. 目录页用了 01/02/03——功能清单不是序列，是模板装饰。

改法：印章页上半屏改为「今天到目前为止」的完整曲线 + 虚线「＋」章位；午后文案缩短并给卡片留白；编号改为分组（玩/一起/记录/这只鸭子）。

## C · 摄影机（`C-viewfinder.html`）

第一轮看到的最伤三处：
1. 动作卡上的字形、名字、说明叠在一起糊成一团。
2. 四张明信片像同一张图印了四次。
3. 胶片页中间空出一大片。

改法：卡改成「琥珀圆徽记 + 名字 + 一行短注」的纵向排布；明信片用四种裁切与缩放（头、脚、左、右）；胶片页把说明上移、帧上的时间标签放大到 8px。


## A · 完整一套（`A-complete.html`，2026-11-21）

第一轮看到的最伤三处：
1. 三列手机的标签是一行长句，把列撑得比手机宽，第一行被挤成两行——版式塌了。
2. 地平线横穿鸭子膝盖，看起来像渲染错误。
3. 老板要求的「完整页面」里，仪表原来没有入口，日记只是抽屉里一格。

改法：
- 列宽锁定 390（与手机同宽），标签在宽度内折行。
- 地平线降到脚踝以下（bottom 34%），地面渐变起点下移；鸭子蒙版再放宽一圈，裁切边彻底看不见。
- 仪表成为墙上的第二件东西（黄铜指针的气压表，在钟的下面），点开是整块墙板；日记在抽屉「记录」组里是一格发亮的镀层，点开是柜子的第二层抽屉（账本行：时间 + 真事 + 次数）。
- 顶部小标改成整句（去掉全大写小标签式的模板装饰）。

交互（都在主屏上可直接试）：
- 喂食：碗里的饭少一口，计数器 +1；见底时添一口，回到满。
- 技能：从卡盒抽一张，鸭子转一圈，字幕报出它做了什么。
- 叫一声：铜铃起涟漪，鸭子抖一下。
- 拎起：鸭子被抬起来，脚还在蹬；再点放下。
- 柜子：拉出四组抽屉，点一行展开说明；「日记」打开第二层账本。
- 墙上钟：时间机器，拖着指针往回拨，事件按远近亮起。
- 墙上仪表：身体三条、三个传感器、今天一行真数字。


## A · 钟与表分开（2026-11-21，第二轮）

用户指出的最伤三处：
1. 钟和表都是圆盘黄铜边，一眼分不清哪个是钟、哪个是读数表。
2. 仪表只有一根针，看不出「读数装置」。
3. 两个详情页都是同一种深色板，材质没拉开。

改法：
- 钟改成木壳长条挂钟：竖向木纹外壳、顶部吊钩、底部黄铜摆锤、面板上 15/16 两个小时间数字；刻度是一条竖向刻度梯，琥珀色的「指针」横在刻度上，抓它往回拨。去掉了圆表盘和圆黄铜边。
- 气压表保留圆形黄铜壳，但加厚了沿口与内圈，表盘换成密刻度（每 9° 一格），两根针（黄铜=气压、琥珀=室温），盘面标 hPa，下面写「读数」。
- 详情页材质分开：时间机器 = 木壳（竖向木纹、四角黄铜铆钉、琥珀滑钮）；墙上的仪表 = 黄铜边读数板（三只圆形多针量表 62/88/不错，取代原来三条横条，板角有黄铜铆钉）。
- 主屏两者上下并排：挂钟在右上、气压表在它下面，形体一竖一圆，材质一木一铜。

## A · 墙上物件缩小一档（2026-11-21，第三轮）

- 气压表 64 → 54；沿口 4px→3px，针长 22→18 / 17→14，支点 6→5，hPa 6→5px，“读数”标签 9→8px。
- 两件在墙上的位置各向角落收 2px，鸭子与床头柜成为画面的绝对主体。
