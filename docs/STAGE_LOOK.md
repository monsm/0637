# 舞台 Look · Live / Instrument / Director 三种视觉语言

> 阿雅（UI/UX）· 2026-11-12 · 配套：`docs/UI_TOKENS.md`、`docs/UI_AUDIT_2026-11-12.md`

---

## 0. 一句话

**Live 应该是"房间"，Instrument 才是"实验室"，Director 是"取景器"。现在三个都是同一个蓝灰网格地板加一块死黑，所以 Live 像仿真器，Director 像悬浮，Instrument 像实验室——只是它长得跟 Live 一样。**

## 2. Live · 房间

### 2.1 地面

| 项 | 现在 | 改成 |
|---|---|---|
| albedo | 棋盘两色 `(0.20,0.30,0.40)` / `(0.10,0.20,0.30)` | **暖石单色 `#38322C`**（约 `(0.22,0.205,0.19)`），不画格 |
| 粗糙度 | 0.85（棋盘分支） | 0.9+，哑光，像打磨过的水泥地而不是塑料 |
| 接触阴影 | 系数 0.55 | 0.62，影子更实，鸭脚踩得住 |

Live 想要"地方感"就用地平线处的极淡雾化，**不要格线**。格线是给仪表盘的语言。

### 2.2 背景

从"一块死黑"改成**竖向渐变 + 鸭身后的暖光晕**：

- 地平线 `#1A1714`（暖褐）→ 天顶 `#0C0E12`（冷蓝黑）
- 鸭身后半径约 1.2 m 的径向暖光 `#FFD9A8` @ 8%：让鸭子从背景里"浮"出来，而不是贴在背景上

### 2.3 相机模式没有地面

Director 打开时地面整块不画（`Renderer.swift:352-359`）——相机画面当底是对的。但要补两块：

1. **接触阴影盘**：鸭子脚下一块半透明的椭圆阴影（深色、软边），压在相机画面上。没有它，鸭子是"贴纸"。
2. **相机不可用时不要悬空**：现在 Android 走冷蓝渐变合成（`PhotoCapture.kt:38-46`），iOS 走透明底。把这条回退路径改成和 Live 同一套暖石地面 + 光晕——否则用户在无权限时拍到的照片和 Live 屏长得不一样。

## 3. Instrument · 实验室（保留冷蓝棋盘）

冷色棋盘在仪表盘里是**正当语言**，不要改：

- 地面 `#24262B`，棋盘 `#33404F` / `#1A2229`，0.2 m 一格
- 保留遥测网格与刻度感：这是"这里能看到数字"的地方
- 唯一要求：Instrument 与 Live 之间切换时，**视觉语言切换要能被感知**（暖 ↔ 冷），别让用户以为换了个 App

---

## 4. Director · 取景器

- 取景器画面比例、画幅角标、快门位置**不动**（那是相机语义，别改）
- 但快门拍下来的成片要按 4:5 裁切（社交平台友好）
- 成片底部预留**字幕带**（见 §5），预览里所见即所得

---

## 5. 明信片：合成成片再分享

### 5.1 问题

caption（被摸 / 喂食 / 仪式 / 摔倒 / 情绪 / 米数，**全是真实计数**）已经算出来了，却只活在 App 的元数据里；分享交出去的是一张裸 PNG，日期也没有。用户要发出去的图里带的是 20 cm 一格的官方棋盘。

### 5.2 规格

保存时合成一张成片：

```
┌─────────────────────────────┐
│                             │
│        鸭子的照片            │
│                             │
├─────────────────────────────┤
│ 被摸了 3 次 · 摔了 1 次  2026-11-12 │
└─────────────────────────────┘
```

- 图 + 底部一条深色字幕带：高度 = 图高 12%，底色 `#000000` @ 55%
- 左侧 caption：13 pt rounded，`text.primary`
- 右侧日期：11 pt，`text.primary` @ 70%
- 右下角小字标 `MicroDuck`：9 pt，`text.primary` @ 45%
- **原帧另存**（`frame-*.png`），成片存 `card-*.png`，方便以后换样式重新生成
- 分享交**成片**，不是原帧
- **caption 一字不改**：它必须还是真数字真事件，不能为了好看编句子

## 6. 图标：让它和 App 里那只是同一只

现在 `brand/icon-512.png` 是一只极简几何橡皮鸭（两个白圆 + 黑点眼 + 橘圆喙 + 橘圆脚），底是深藏青渐变。App 里跑的是一只**白壳 + 橙喙 + 橙脚的机器人**（带轮子、分节、镜头镜筒、淡粉软嘴、琥珀鼻钉）。

**它俩不是同一只。** 而且图标内部就犯了和 UI 一样的病：喙 `#FF7A1A`、脚 `#FF9829`——同一只鸭身上的同一种橙，两个值。

### 6.1 规格

- 主体：3D 鸭子的**剪影**——白壳、橙喙、橙脚，保留一点"机器"的特征（一条分节缝、镜头点），让它跟 App 里那只一眼能对上
- 颜色：喙 / 脚统一用 **`#FF671F`**（3D 材质那个橙）；底用 `brand.canvas` = `#121110` → `#1A1714` 的暖黑渐变，跟 Live 舞台同一套
- 接地阴影：脚下加一小块软影，现在鸭子是浮着的
- 48 px 下的取舍（实测现在的问题）：眼只剩 3×3 px、头身并成一坨、靠一块灰投影分辨出"有头"、两只脚与身体直接相接像"贴了两块橙"
  → **48 px 只保留三个形状**：剪影 / 喙 / 脚；眼放大到 ≥ 4 px 且加大头身之间的暗色缝隙；脚与身体之间留暗色间隙
- 补齐资产：`brand/` 补 SVG 源文件 + `colors.json`；Android 补 `mipmap-anydpi-v26` 自适应图标（现在**完全没有**）；修掉假的 `ic_launcher_round`（5 个密度与方形图 md5 相同，根本不是圆的）；iOS AppIcon 补深色 / 染色变体

## 7. 怎么落地

### 7.1 舞台（两端各约 10 行）

加一个 look 标志进 uniform（`live` / `instrument`）：

- Metal：`Shaders.metal` 的 `uniforms.light.w > 0.5` 分支里再分一次；`Renderer.swift:356-358` 按当前 surface 传值
- GL：`DuckRenderer.kt` 同理，`uChecker` 保留给 Instrument
- 背景渐变与暖光晕：可以先在 clearColor 上做（iOS 一行、GLES 一行），不够再加一层全屏三角

**不动物理，不动鸭子的 61 维观测与安全层。** 相机、接触阴影、光照方向都不改。

### 7.2 明信片（两端各一个合成函数）

- iOS：UIGraphicsImageRenderer，底图 + 字幕带 + 三段文字
- Android：`Canvas` + `Paint`，同版式
- 文案复用现有 `Copy.awayPets/awayFeeds/awayRituals/awayFalls/awayMoods/postcardMetres`

### 7.3 验收截图清单（缺一不可）

1. Live 竖屏空闲态（**当前没有这张图**，三张 iOS 截图实为横屏或旋转图且比代码旧一天）
2. Live 竖屏 + 画路走模式
3. Live 竖屏 + 技能盘打开
4. Live 竖屏 + 渲染失败态
