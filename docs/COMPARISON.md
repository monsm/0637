# 数字版 × 物理版 · 全维度横评（2026-11-09 阶段性）

> 物理版：Pollen Robotics × Hugging Face MicroDuck —— ~25 cm、~770–800 g、14 个仿真关节 + 头部 4 轴、
> XL330 舵机、RK3566（1 GB RAM / 32 GB 存储）、单目"一只眼"+ 麦克风 + 扬声器 + 深度传感器 + IMU、
> robotd 50 Hz 控制 + BAM 执行器模型 + JSON-RPC/NDJSON 协议。
>
> 数字版：iOS（SwiftUI + Metal）与 Android（Compose + GLES3）双端，同样的官方 MJCF + 官方 ONNX + 官方
> robotd/duck-control 代码，MuJoCo 3.10 在端内跑物理。开发全部在 GitHub Actions CI 完成（无本地移动构建；
> 模拟器/模拟机实跑验证，iOS 33/33 + XCUITest，Android 冒烟）。

## 三把尺子

| 基准 | 定义 | 可达的 "100%" 含义 |
|---|---|---|
| 官方模型 | 同一 MJCF + BAM M6 + ONNX + robotd | 行为等价，可逐字段验证 |
| 某一台真机 | 你的那一只（制造差异、磨损、温度…） | 需遥测做系统辨识；逐帧一致在混沌意义下不可能 |
| 整个产品 | 数字版还要加上手机传感器/AR/新交互 | 传感器层未开始 |

## 保真度分级（沿用 FIDELITY.md）

- **L1 模型一致**：✅ 100% —— 同一 MJCF + 38 mesh + 关节/动力学/执行器
- **L2 运动一致**：✅ 100%（对官方模型）—— 策略原样 + 编码器/反射/平滑/时序/空闲行为全部对齐，CI 逐项实测（行走 ~0.5 m、坐/站、3 技能、抓地、推挤、重载）
- **L3 场景一致**：✅ 100%（物理）/~90%（视觉）
- **L4 单机硬件一致**：❌ 0% —— 声明不可达，需真机遥测做系统辨识才能逼近

## 已知差距（未做）

- 相机 / LiDAR / AR 模式、麦克风：M3 之后的传感器层
- PBR 材质、阴影、反光、天空盒：视觉打磨
- 真机性能/发热/50 Hz 抖动：未测（无物理设备）
- 时间机器、Duck Bench（agent 评测场）、MCP 端点、策略商店：规划中
- 磁盘上的扁平 manifest 已兼容，但自定义策略的"试运行再换"还没做
